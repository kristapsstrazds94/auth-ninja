# Cursor agent files

These files power **`/next`**, **`/task`**, and related slash commands for building Auth-Ninja.

| Path | Purpose |
| --- | --- |
| `commands/` | Slash command prompts |
| `skills/` | Step-by-step implementation protocols |
| `rules/` | Persistent security and monorepo constraints |

**Not published to npm.** Consumer projects only receive `packages/*/dist`.

Local scratch notes go in `.cursor-ai/` (gitignored).
